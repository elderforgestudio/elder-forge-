Sword Blade Short

Sword Blade Short es un juego arcade de acción rápida donde tu espada es tu única herramienta para sobrevivir. Enfréntate a oleadas de objetos que aparecen desde todas las direcciones y destrúyelos antes de que sea demasiado tarde. Cada corte cuenta: consigue combos, aumenta tu puntuación y demuestra qué tan rápido puedes reaccionar.

🗡️ Corta. Sobrevive. Consigue el récord. Características: ⚔️ Combate rápido basado en cortes. 💥 Combos y puntuaciones altas. 🌌 Estética pixel art espacial. 🗡️ Diferentes espadas para desbloquear. 🏆 Sistema de récords y progresión. ⏱️ Partidas cortas, pensadas para jugar rápidamente.

Como descargar vercion veta
  1. Presiona el botón de descarga para comenzar.
  2. Puedes apoyarnos realizando una donación o continuar directamente con la descarga seleccionando el enlace indicado.
  3. Presiona nuevamente el botón de descarga para iniciar la descarga del archivo.
  4. Una vez finalizada la descarga, localiza el archivo en la carpeta donde se guardan tus descargas.
  5. Descomprime el archivo descargado utilizando cualquier programa compatible con archivos comprimidos.
  6. Una vez descomprimido el archivo, abre la aplicación Sword Blade Short.exe para iniciar el juego.
